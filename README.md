# Project Title: CSE110_Final_Project
## Description: Final project for CSE1106 at UTA, integrates the usage of GitHub, RaspberryPi, and a circuit to produce a functional program that can be visualized directly. This program is an implementation of Option 1: A Smart Classroom Comfort Monitor. Takes readings by prompting the user, determines whether or not a temperature is out of range with a warning light.
## Technologies: C language, RaspberryPi, Breadboard and wires, User Input.
## How To Run: Open Terminal, enter: 'cd cse1106/CSE1106_Final_Project', compile using 'gcc Smart_Classroom.c -o smartClassroomOut', run using './smartClassroomOut'
